# Armor glint vertex execution fixture

This original diagnostic pack exercises the supported armor-glint vertex bridge, including legacy position, texture-coordinate, and color aliases. Its `flat` green output checks that Veyra preserves interpolation across the vertex and fragment stages. The graphics smoke equips an enchanted book and verifies that the custom signal appears while the pack is active and disappears after disabling it. It does not claim that a complete third-party shaderpack has been visually validated.
