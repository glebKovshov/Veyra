# Shared shadow and compute images

Original diagnostic using the production shaderpack lifecycle: terrain shadow vertices read the native block atlas and lightmap, then atomically write a voxel only when the sampled alpha and light are positive. `shadowcomp.csh` writes an SSBO dispatch count and an intermediate image; `shadowcomp_a.csh` consumes the count through `indirect.shadowcomp_a`, completes the volume, and terrain samples the result. The first stage's `workGroupsRender` exercises render-relative dispatch, while the second uses Iris `indirect.<pass>` sizing. Bounds checks keep writes inside the 4x4x4 image after resize. Magenta requires value 42 from the complete chain; clearing, missing vertex execution, skipped indirect dispatch or separate image allocations cannot produce it. Disabling the pack must remove the signal and retire its resources.
