# Shared shadow and compute images

Diagnostic using the production shaderpack lifecycle: terrain shadow vertices read the native block atlas and lightmap, then atomically write a voxel only when the sampled alpha and light are positive. `shadowcomp.csh` writes an SSBO dispatch count and an intermediate 3D image; `shadowcomp_a.csh` consumes the count through `indirect.shadowcomp_a`, completes the 3D volume, and writes the same computed value to a 2D custom image. Terrain samples both images. The first stage's `workGroupsRender` exercises render-relative dispatch, while the second uses Iris `indirect.<pass>` sizing. Bounds checks keep writes inside the 4x4x4 resources after resize. Magenta requires value 42 from both compute image dimensions; clearing, missing vertex execution, skipped indirect dispatch, 2D allocation failure or separate image allocations cannot produce it. Disabling the pack must remove the signal and retire its resources.
