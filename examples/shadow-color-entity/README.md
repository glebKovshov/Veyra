# Shadow color readback

Original diagnostic reading the actual completed shadow color attachment through both shadowcolor0 and its legacy shadowcolor alias. A small grid must find the authored shadow-pass output; clear/default textures cannot pass. The entity variant uses a camera-relative test-world cow. The shared shadow vertex stage emits a flat material varying consumed by the entity shadow fragment, so the fixture also checks that the entity shadow pipeline loads and links the pack's selected `shadow.vsh`. General shadow formats, additional color attachments and mipmap properties are not implemented by this fixture.
