# Shadow color readback

Original diagnostic reading the completed shadow color attachment through both shadowcolor0 and its legacy shadowcolor alias. Terrain writes a blue marker and the entity-specific shadow_entities program writes green. Its test vertex shader forces a large near-depth footprint so the color-write check does not depend on natural entity shadow placement or sparse sampling. final.fsh scans the full shadow map and marks matching samples magenta; terrain writes cannot pass the entity fixture. The entity fragment output is constant so the check does not depend on custom varyings. General shadow formats, additional color attachments and mipmap properties are not implemented by this fixture.
