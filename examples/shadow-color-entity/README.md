# Shadow color readback

Original diagnostic reading the completed shadow color attachment through both shadowcolor0 and its legacy shadowcolor alias. Terrain writes a blue marker and the entity-specific shadow_entities program writes green. Its test vertex shader forces a large near-depth footprint at OpenGL shadow UV 0.1–0.35 in both axes. final.fsh marks matching color aliases and zero depth magenta only inside that expected region, so a vertically mirrored shadow map fails the gate. Terrain writes cannot pass the entity fixture. The entity fragment output is constant so the check does not depend on custom varyings. General shadow formats, additional color attachments and mipmap properties are not implemented by this fixture.
