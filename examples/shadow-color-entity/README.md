# Shadow color readback

Original diagnostic reading the completed shadow color attachment through both shadowcolor0 and its legacy shadowcolor alias. Terrain writes a blue marker and the entity-specific shadow_entities program writes green; only the green marker can turn the test-world cow magenta, so terrain writes cannot pass the entity fixture. The entity vertex stage emits the varying consumed by its fragment shader. General shadow formats, additional color attachments and mipmap properties are not implemented by this fixture.
