# Composite custom-image consumer

This diagnostic uses the production shaderpack lifecycle. Shadow terrain writes the value 5 to `voxel_img`, and `shadowcomp.csh` adds 37 into the shared `floodfill_img`. Compute-only `prepare.csh` sets a 2D custom image to 7, `deferred.csh` adds 10, and SSBO-only `deferred2.csh` writes 11 to `bufferObject.0`. `composite.csh` reads that buffer and adds its value, then `composite_a.csh` adds 14 before `composite.fsh` samples 42. A compute-only `composite1.csh` pass adds one after that fragment pass; `final.fsh` verifies 43. The full-screen output becomes magenta only when the prepare, deferred and composite dispatches run in phase and pass order and the SSBO write is visible to its next compute consumer. This also checks that the `clear=true` image starts clean each frame. Disabling the pack removes the magenta signal.
