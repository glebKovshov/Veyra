# Composite custom-image consumer

This diagnostic uses the production shaderpack lifecycle. Shadow terrain writes the value 5 to `voxel_img`, and `shadowcomp.csh` adds 37 into the shared `floodfill_img`. Compute-only `prepare.csh` sets a 2D custom image to 7, `deferred.csh` adds 10, then `composite.csh` and `composite_a.csh` add 11 and 14 before `composite.fsh` samples 42. A compute-only `composite1.csh` pass adds one after that fragment pass; `final.fsh` verifies 43. The full-screen output becomes magenta only when the prepare, deferred and composite dispatches run in phase and pass order. This checks that ordered components see previous writes and that the `clear=true` image starts clean each frame. Disabling the pack removes the magenta signal.
