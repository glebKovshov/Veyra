# Terrain and entity view-space inputs

This example uses the Iris `viewPos` varying in both terrain and entity fragment programs. The terrain fragment also checks Iris `dist`, the smooth view-space distance calculated at each vertex from `gbufferModelView * pos`. It checks the Iris `normal`, `tangent`, `binormal`, and `viewVector` inputs reconstructed from view-position and UV derivatives: the basis must be orthonormal, and the tangent-space view vector must preserve the view-position length. The terrain signal is magenta when the view position, distance, and tangent frame checks pass; green identifies an invalid input or basis.

The Lavapipe smoke fixture reads back the terrain signal from the presented `colortex0` image while shaders are enabled and disabled. This example declares no auxiliary MRT target, so its check does not require `colortex1`. It checks the synthetic Veyra bridge; it is not a third-party shaderpack visual-compatibility result. The derivative basis is suited to planar terrain surfaces and does not provide arbitrary per-vertex tangent attributes for custom terrain geometry.
