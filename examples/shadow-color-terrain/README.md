# Shadow color readback

Original diagnostic reading the completed shadow color attachment through both shadowcolor0 and its legacy shadowcolor alias. The custom shadow vertex stage checks at_midBlock and emission, projects through the shadow matrices, and sends a blue varying to the fragment stage. The fixed 640x360 smoke frame samples the map over its full extent, so the check follows the pack's shadow angle instead of assuming a particular light direction; clear/default textures cannot pass. General shadow formats, additional color attachments and mipmap properties are not implemented by this fixture.
