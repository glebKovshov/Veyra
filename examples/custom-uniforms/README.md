# Custom uniforms

Place this folder in `shaderpacks/` and select it with F6 in a world at noon. `shaders.properties` defines OptiFine/Iris `uniform.*` and `variable.*` expressions (float, int, bool, helper variable, line continuation). Magenta terrain means both `gbuffers_terrain` and the `final` post pass received the expected CPU-evaluated values; green means a value was wrong.

This is an original diagnostic fixture used by the software Vulkan integration matrix.
